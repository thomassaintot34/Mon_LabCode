PROJET- 2: Manipulation d'objet JS

Présentation

Ce second projet met en pratique la manipulation avancée de données sous forme de tableau interactif. L'objectif est d'exploiter un jeu de données structuré représentant un effectif sportif (U18F) pour effectuer des filtrages croisés en temps réel (par poste, disponibilité et année de naissance), tout en offrant une navigation interactive et dynamique vers les fiches individuelles de chaque joueuse.

Techniques utilisées

  • Tableaux HTML : Structuration sémantique avec les balises conventionnelles <table>, <thead> et <tbody>.
  • Manipulation de données : Exploitation des méthodes natives JavaScript (telles que filter() et forEach()) pour traiter les objets et appliquer des critères stricts.
  • DOM Dynamique : Injection, mise à jour instantanée des lignes du tableau et gestion des écouteurs d'événements (change et click) pour une UI réactive.
  • Navigation interactive : Redirection dynamique vers des fiches individuelles via l'exploitation des identifiants uniques.
